# SaugatCho.github.io(HomePage)
[Click here to view](https://SaugatCho.github.io/)


## Project files

- `index.html` — homepage content and links
- `style.css` — page layout, gradients, and responsive styles
- `manifest.json` — app name, launch path, and theme metadata
- `favicon.svg` — homepage icon
- `.nojekyll` — keeps GitHub Pages from running Jekyll processing

This homepage is static and does not need an `app.js` file. The manifest is metadata only; there is no service worker or guarantee of offline installation.
